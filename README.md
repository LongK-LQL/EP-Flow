
# EP-Flow

**EP-Flow: Disordered Crystal Structure Prediction without Site-Level Annotations**

Accepted at **NeurIPS 2026**.

## Overview

EP-Flow (Entropic Polytope Flow) is a flow-matching framework for disordered crystal structure prediction without site-level disorder annotations.

By introducing an Occupancy Distribution Matrix (ODM) and transportation-polytope constraints, EP-Flow jointly generates site occupancies, fractional coordinates, and lattice parameters while preserving compositional consistency.

The method is evaluated on disordered crystal structure benchmarks derived from COD and MPDS.
